# Physiology of the Motor System

Repository for developing the graduate course **Physiology of the Motor System**
(Biomedical Engineering Department, Ben-Gurion University), and for the
AI-assisted processes used to develop its instructional materials.

## Status

The existing course is complete (syllabus, textbook chapters, research papers,
slide decks, assignments, lecture recordings/transcripts). None of that material
is imported here. We are currently **designing the development process**, not
redesigning the course. No coordinator or specialist skills are implemented yet.

## Contents

- [`AGENTS.md`](AGENTS.md) - brief guidance for agents working in this repository.
- [`docs/principles-and-questions.md`](docs/principles-and-questions.md) - accepted architectural principles and open questions.
