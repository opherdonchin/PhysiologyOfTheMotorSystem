# AGENTS.md

Repository-level guidance for agents working on the Physiology of the Motor System course.

## Status

This repository is at initialization. The Course Coordinator and the specialist
(lecture, paper-discussion, artifact) processes are **not yet implemented**.
Do not create them, copy the PML pipeline, or install HILD without an explicit
instructor instruction.

## Rules that apply now

- Read [`docs/principles-and-questions.md`](docs/principles-and-questions.md) first; its accepted principles are binding starting constraints.
- Work starts from instructor instructions. Surface issues with evidence, options and a recommendation. Apply a fix unasked only when there is one obvious solution, and report it. Consequential choices need specific instructor approval; silence is not approval.
- Do not make new pedagogical or architectural decisions. Record them as open questions in their owning document and list a pointer in [`docs/instructor-review-queue.md`](docs/instructor-review-queue.md).
- Do not invent the contents of inaccessible references; report them as inaccessible.

## Temporary restrictions

These apply during initialization only and lapse for a given item when the
instructor explicitly authorizes it; they are not permanent policy:

- Do not import copyrighted readings, classroom transcripts or previous slides. Import will be considered when the instructor authorizes it and source authority (Q5) is settled.
- Do not implement the Course Coordinator or specialist skills, copy the PML pipeline, or install HILD.
